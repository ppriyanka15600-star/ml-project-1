Email Spam Detection using Machine Learning

📌 About the Project

This project classifies emails as Spam or Not Spam (Ham) using Machine Learning techniques.
It helps automatically filter unwanted emails and improve user experience.

---

🎯 Problem Statement

With the increasing number of emails, identifying spam manually is difficult.
This project aims to build a model that can accurately detect spam emails based on text data.

---

🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)

---

📊 Dataset

- Source: Kaggle
- Features:
  - Email/SMS text
- Target:
  - 0 → Not Spam (Ham)
  - 1 → Spam

---

⚙️ Project Workflow

1. Data Collection
2. Data Cleaning
3. Text Preprocessing
   - Lowercasing
   - Removing stopwords
   - Tokenization
4. Feature Extraction (TF-IDF / Count Vectorizer)
5. Model Training (Naive Bayes / Logistic Regression)
6. Model Evaluation

---

▶️ How to Run the Project

pip install -r requirements.txt
python spam_detection.py

---

📈 Results

- Model Accuracy: 0.5
- The model performs well in identifying spam messages with good precision and recall.
